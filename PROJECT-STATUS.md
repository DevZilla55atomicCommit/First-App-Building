## Build state

- **Status: BLOCKED — cannot run `flutter` in this environment.**
- Every `flutter` command exits 1 with:
  ```
  /opt/homebrew/share/flutter/bin/internal/update_engine_version.sh: line 71:
      .../bin/cache/engine.stamp.tmp.<pid>: Operation not permitted
  /opt/homebrew/share/flutter/bin/internal/update_engine_version.sh: line 78:
      .../bin/cache/engine.realm: Operation not permitted
  ```
- **Root cause:** macOS TCC blocks all writes to `/opt/homebrew` (where the
  Homebrew-installed Flutter SDK and its cache live). `update_engine_version.sh`
  rewrites `engine.stamp`/`engine.realm` on every invocation; the cache is fully
  populated, but the CLI refuses to run without the write.
- **No in-session workaround:** no sudo, no ACL/tccutil/lsattr, no access to
  `/tmp`, `/var/folders`, or the home dir. The block persists with the Bash
  sandbox disabled.
- **Workarounds (outside this session):**
  1. Run Flutter commands in a normal Terminal.app session (not the Bash tool),
     or a new Claude session without the Bash tool's TCC restrictions; or
  2. Grant TCC write access to `/opt/homebrew` (System Settings → Privacy &
     Security → File and Folder Access); or
  3. Reinstall Flutter to a writable location (e.g. `~/dev/flutter`).
